# ☕ Cafe Management System

## 📌 Overview

Cafe Management System is a desktop application developed using **C++** to help manage daily operations in a cafe.
The system simplifies order processing, product management, employee management, and sales tracking.

The application supports two main user roles:

* **Admin (Manager)** – manages products, employees, and monitors sales.
* **Employee** – creates customer orders, selects products, calculates totals, and generates receipts.

The goal of this project is to organize cafe operations and provide a fast and efficient way to handle orders and sales.

---

## 🚀 Features

### 🔐 Authentication

* Login system for **Admin** and **Employee**

### 👨‍💼 Admin Features

* Admin Dashboard
* Add / Edit / Delete Products
* View Orders and Order History
* Manage Employees
* View Reports and Analytics
* Manage Inventory
* System Settings

### 👨‍🍳 Employee Features

* POS (Point of Sale) System
* Create Customer Orders
* Select Products and Quantities
* Calculate Total Price
* Generate and Print Receipt
